# Jano: Solsticio - Web

Repositorio para la web promocional del juego **Jano: Solsticio**.

## 1. Título y Contexto
* **Título:** Jano: Solsticio.
* **Género:** Acción arcade en perspectiva isométrica.
* **El Concepto:** Una partida rápida que dura un máximo de 5 minutos. El jugador debe abrirse paso entre enemigos mientras su personaje y el mundo envejecen visualmente a través de las 4 estaciones (de Primavera a Invierno), luchando por completar el ciclo antes de que se agote su tiempo.
* **Mecánica clave:** Accesibilidad extrema. Movimiento básico de 8 direcciones y un sistema de combate de un solo botón que rota cíclicamente entre tres habilidades (Dash ➔ Escudo/Melee ➔ Ataque a distancia).

## 2. Estilo Visual y Tono
* **Estética del juego:** Arte 3D simple, geométrico y estilizado.
* **Dirección para la web:** Diseño minimalista, centrado en lo visual. El diseño de la página debería reflejar el contraste de las estaciones, pasando de colores vivos (primavera) a tonos fríos y blancos (invierno).
